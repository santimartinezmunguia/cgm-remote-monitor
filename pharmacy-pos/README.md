# Pharmacy POS Application

This is a simple command-line based Point of Sale (POS) application for a pharmacy.

## Features

* Add new products to the inventory.
* List all products in the inventory.
* Sell products.
* Search for products.

## How to Run

1.  Navigate to the `pharmacy-pos` directory:
    ```bash
    cd pharmacy-pos
    ```

2.  Run the application using Python:
    ```bash
    python main.py
    ```

This will start the application and you will see a menu with options to choose from.
